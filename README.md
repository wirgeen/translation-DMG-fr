# D&D 5e – Traduction FR – Guide du Maître de Donjon

Module FoundryVTT (v13+) de traduction française du compendium officiel **Dungeon Master's Guide 2024** pour le système dnd5e.

## Dépendances

- Système : [dnd5e](https://foundryvtt.com/packages/dnd5e)
- Module requis : `dnd-dungeon-masters-guide` (contenu officiel D&D)
- Module recommandé : [Babele](https://foundryvtt.com/packages/babele) (traduction automatique des compendiums)

## Installation

1. Copier le dossier `translation-DMG-fr` dans `[FoundryVTT Data]/modules/`
2. Activer le module dans les paramètres du monde
3. Activer également Babele si ce n'est pas déjà fait
